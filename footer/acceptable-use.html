Acceptable Use Policy

Last updated: August 18, 2026

Overview

Loophole is an open-source AI code editor built to help developers write, understand, and improve software. Because Loophole is free software and routes all AI requests directly from your machine to your chosen provider, we have no technical mechanism to monitor or enforce usage in real time. This Acceptable Use Policy reflects our values as an open-source project and the ethical expectations we hold for ourselves and our community. Violations of this policy may result in removal of contributions, bans from community spaces, and reporting to relevant authorities where required by law.

Permitted Use

Loophole is intended for lawful software development. Permitted uses include:

  • Writing, editing, debugging, and reviewing code for personal, commercial, or open-source projects
  • Using AI chat (Normal, Gather, Plan, and Agent modes) to assist with software engineering tasks
  • Using inline autocomplete, Quick Edit (Ctrl+K), and AI commit message generation during development
  • Running the agentic engine to automate legitimate development workflows with appropriate approval controls enabled
  • Connecting to AI providers of your choice, including local models via Ollama, vLLM, or LM Studio
  • Extending Loophole with MCP servers and VS Code extensions for legitimate development tooling
  • Modifying and redistributing Loophole under the terms of the AGPL-3.0 license
  • Using Loophole in professional, educational, research, and hobbyist contexts
Prohibited Use

You may not use Loophole for any of the following:

  • Malicious software. Creating, distributing, or deploying malware, ransomware, spyware, trojans, keyloggers, or other software intended to harm systems or users without authorization
  • Unauthorized access. Writing or using code to gain unauthorized access to systems, networks, accounts, or data you do not own or have explicit permission to access
  • Illegal activity. Using Loophole to develop software for any purpose that violates applicable local, national, or international law
  • Abuse of agentic features. Using the agentic engine's file read/write, terminal execution, or sub-agent spawning capabilities to perform actions on systems you do not own or control
  • Privacy violations. Building tools designed to surveil, track, or harvest data from individuals without their informed consent
  • Harassment tooling. Developing software whose primary purpose is to facilitate harassment, stalking, abuse, or targeted harm toward individuals or groups
  • AI provider abuse. Using Loophole to circumvent, abuse, or violate the terms of service of any connected AI provider
  • License violations. Distributing modified versions of Loophole without complying with the AGPL-3.0 license, including failing to release source code of modifications
  • Misrepresentation. Claiming that your modified fork of Loophole is the official Loophole project, or using the Loophole name and branding in ways that mislead users
Agentic Mode Responsibility

Loophole's Agent mode gives the AI full tool access: it can read files with pagination, write and overwrite files, create and delete files and folders, rename and move paths, run terminal commands, open persistent terminal sessions, search the codebase, and spawn parallel sub-agents. These capabilities are intentionally powerful and require deliberate oversight. You must review and approve agent actions through the built-in per-category approval controls before enabling auto-approve. You are fully responsible for all actions taken by agents you configure and run. Do not point an agent at systems, directories, or files you are not authorized to modify.

AI-Generated Code

Loophole's AI features produce probabilistic outputs. AI-generated code may contain errors, security vulnerabilities, or incorrect logic. You are responsible for reviewing, testing, and validating any AI-generated output before deploying it to production systems. Do not use AI-generated code in safety-critical systems without thorough human review and appropriate testing. Loophole and its contributors accept no liability for harm arising from AI-generated code you deploy.

Community Standards

Loophole is an open-source community project. Participation in the GitHub repository — through issues, pull requests, discussions, and code review — is subject to respectful and inclusive behavior. We welcome contributors from all backgrounds and experience levels. Harassment, discrimination, or bad-faith behavior in community spaces will result in removal. See the Contributing Guide for community expectations.

Reporting Violations

If you believe someone is using Loophole in violation of this policy or is engaging in harmful activity through community spaces, please report it by opening an issue on our GitHub repository. For security-related concerns, use the private reporting process described in our Security Policy.

Updates to This Policy

We may update this Acceptable Use Policy from time to time to reflect changes in how Loophole is used or to address new concerns. Changes will be announced in the repository and the "Last updated" date above will be revised.
