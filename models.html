Local & Self-Hosted

Run fully offline. No internet, no API key, no data leaving your machine.

Ollama
local

Models are auto-detected from your local Ollama instance. Pull any model from the Ollama library and it appears instantly.

default endpoint http://127.0.0.1:11434
llama3.3 deepseek-r1 qwen3 mistral codellama + any Ollama model
LM Studio
local

Connect to LM Studio's local server. Download models from Hugging Face directly inside LM Studio and use them in Loophole.

default endpoint http://localhost:1234
Any GGUF model HuggingFace models + any LM Studio model
vLLM
local

Point Loophole at your vLLM server. Models are auto-detected. Ideal for running high-throughput inference on your own hardware.

default endpoint http://localhost:8000
